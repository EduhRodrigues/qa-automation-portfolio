# Bug Report

## BUG-001 - Funcionalidade Editar Produto não funciona

### Descrição
Ao clicar no botão "Editar" de um produto cadastrado pelo usuário autenticado, nenhuma ação é executada.

### Passos para reproduzir

1. Efetuar login
2. Cadastrar um produto
3. Acessar Listar Produtos
4. Clicar em Editar

### Resultado esperado

Usuário deve ser direcionado para a tela de edição do produto.

### Resultado obtido

Nenhuma ação é executada.

### Severidade

Alta
